# Как искать и составлять ребусы

Инструкция для того, кто добавляет ребусы в `public/data/rebuses.json`. Аудитория — дети 5–8 лет. Код при этом трогать не нужно.

## Порядок работы

1. Запустите `npm run stats`. Команда покажет ответы и картинки, которые уже есть в наборе. Повторять их нельзя (см. «Без повторов»).
2. Найдите идеи и соберите каждую в формат ниже.
3. Пройдите по чек-листу в конце.
4. Запустите `npm run validate`. Он должен выдать «проблем: 0». Предупреждения тоже стоит устранить. Если валидатор находит ошибку, `npm run build` не соберётся.

## Где искать

Ищите ребусы для дошкольников и 1–2 класса: детские развивающие сайты, материалы учителей (например, infourok.ru), сборники «ребусы для детей 5–7 лет».

Картинки из источников **не копируем** — это вопрос авторских прав. Берём только идею, то есть слово-ответ и приём, и собираем ребус заново из эмодзи. Если идея не собирается из понятных эмодзи, её пропускаем. В поле `source` указываем ссылку, откуда взята идея. Если ребус известный или придуман самостоятельно, пишем `"классика"`.

Сеть в среде разработки может быть ограничена: страницы не открываются, работает только поиск. Это не повод отказаться от правил ниже. Ребусы можно составлять и самостоятельно.

## Запись ребуса

Используем только классические приёмы, которые ребёнок знает или быстро поймёт. Картинка рисуется эмодзи. Запятые, цифры и прочие значки приложение рисует само по полям из JSON. Для каждого приёма, кроме запятых, приложение один раз само показывает легенду, а потом она открывается по кнопке «?».

**Части** (`parts`) читаются слева направо и склеиваются в ответ:

| Часть | JSON | Как выглядит | Что даёт | Уровень |
|---|---|---|---|---|
| Картинка | `{ "type": "pic", "emoji": "🐈", "word": "КОТ" }` | эмодзи | слово целиком (или с операциями ниже) | любой |
| Буквы | `{ "type": "letters", "text": "ОК" }` | крупные цветные буквы | буквы как есть | любой |
| Первые буквы | `{ "type": "initials", "items": [{ "emoji": "🐭", "word": "МЫШЬ" }, …] }` | 2–4 картинки в рамке, над ней «А…» | первые буквы слов: 🐭🍉🐈 = МАК | 1–2 |
| Число | `{ "type": "number", "value": "7", "word": "СЕМЬ" }` | крупные цифры | число словом: 7Я = СЕМЬЯ, 100Л = СТОЛ; можно с запятыми | 1–3 |
| Буквы в букве | `{ "type": "position", "prep": "В", "outer": "О", "inner": "ДА", "prepFirst": true }` | маленькие буквы внутри большой | `prepFirst: true` — В + внешнее + внутреннее (ДА в О = ВОДА); без него — внутреннее + В + внешнее (СО в А = СОВА) | 2–3 |
| Буквы над буквами | `{ "type": "position", "prep": "НА", "outer": "МА", "inner": "ПА" }` | одни буквы над другими | верхнее + НА + нижнее (ПА на МА = ПАНАМА) | 2–3 |

**Операции над картинкой** (у числа — только запятые):

| Операция | Поле | Как выглядит | Что значит | Уровень |
|---|---|---|---|---|
| Запятые | `cutStart` / `cutEnd` | запятые **вверху** у картинки, слева или справа | убрать столько букв в начале или в конце | 1–3 |
| Зачёркнутая буква | `remove: ["Л"]` | буква под картинкой, перечёркнутая красным | убрать эту букву (первое вхождение) | 2–3 |
| Цифры над картинкой | `pick: [3, 2, 1]` | кружки с номерами над картинкой | взять буквы с этими номерами в этом порядке: часть по порядку (ЛИСА 1 2 3 = ЛИС) или перестановка (НОС 3 2 1 = СОН) | часть — 2, перестановка — 3 |
| Замена по номеру | `replaceAt: [[2, "И"]]` | «2 = И» над картинкой | заменить букву с этим номером | 2–3 |
| Замена буквы | `replace: [["К", "В"]]` | «К = В» над картинкой | заменить все такие буквы | 3 |
| Переворот | `flip: true` | картинка вверх ногами со значком ↺ | прочитать слово задом наперёд | 3 |

Порядок операций в коде: переворот → замены → замена по номеру → зачёркивание → цифры над картинкой → запятые. **На одну картинку — одна операция** (исключение: переворот с запятыми — редко и только на уровне 3). Цифры над картинкой и запятые вместе нельзя.

**Чем отличаются похожие приёмы.** «Две картинки целиком» (🏠 ДОМ + 🌳… без операций) — тоже приём, его стоит использовать: он самый понятный. Первые буквы — хороший приём для 5–6 лет: так дети учатся слышать первый звук. Числа для уровня 1 берём только простые и знакомые: 1 (ОДИН), 2, 3, 5, 7, 100; СОРОК и большие числа — с уровня 2.

**Не используем:** ноты (дети их не читают), дроби (не по программе), «под», «над», «за», «у», «по» (почти нет детских слов, путаются с «на»).

## Как думает ребёнок: картинка и слово

Ребёнок называет картинку **первым словом, которое приходит в голову**. Отсюда правила для поля `word`:

- Слово в **именительном падеже, единственном числе, без уменьшительных форм**: СОБАКА, а не ПЁС и не СОБАЧКА.
- Слово **конкретное, а не обобщающее**: ЯБЛОКО, а не ФРУКТ. ДУБ годится, только если на картинке однозначно дуб.
- Картинку **узнают одинаково на iPhone и Android**. Используем только эмодзи из Unicode ≤ 13. Нельзя: флаги, людей, оттенки кожи, редкие символы.
- **Переворачиваем только то, что узнаётся вверх ногами.** Животное или предмет с чётким силуэтом подходят. Пейзаж и здания — нет.
- **Переворот должен быть виден.** Симметричное и плоское (⚽, 👁️, 🪶, 🥥, 🗺️) вверх ногами выглядит так же — такое не переворачиваем. Переворот вместе с запятыми на одной картинке — только на уровне 3 и редко.

| Эмодзи | Что скажет ребёнок вместо нужного слова | Решение |

## Слово-ответ

- Ответ — существительное из детского мира: животные, еда, игрушки, дом, природа, сказки. Абстрактные слова не берём: не ШУТКА, не ДРУЖБА.
- Ребёнок 5–6 лет должен знать это слово. Например, ДОМИНО им бывает незнакомо, поэтому этот ребус на уровне 2, а не 1.
- Ё в ответе пишем правильно (КОСТЁР, ЛЁД). Когда ребёнок вводит ответ, Ё и Е считаются одинаковыми.
- **Ё и Е не подменяют друг друга в ребусе.** Ребёнок не узнает МЕД в «мёде»: если буква картинки попадает в ответ, Ё остаётся Ё, а Е — Е. Нельзя МЁД → МЕДУЗА, ЁЛКА → ТАРЕЛКА, ,БЕЛКА → ЁЛКА. Это проверяет валидатор (ошибка «Ё/Е»). Срезать Ё запятыми можно. Обрубок слова с Ё не должен читаться странно: из ЩЁТКИ без Щ выходит «ёт», а не «ет».
- Не берём слова, которые в речи заменяются уменьшительной формой: ИГЛА (говорят «иголка»), КИСТЬ («кисточка»).
- `accept` заполняем, только если у ребуса действительно два правильных ответа. Обычно поле пустое.

## Уровни

| Уровень | Для кого | Что можно |
|---|---|---|
| 1 — Лёгкие | 5–6 лет, ребёнок почти не читает | одна операция: картинка с запятыми, первые буквы картинок, простое число, две картинки целиком; 1–2 буквы; слово до ~6 букв, без мягкого знака и «неслышных» букв |
| 2 — Средние | 6–7 лет | 2–3 части; зачёркивание, цифры над картинкой (часть букв), замена по номеру, буквы в букве и над буквами, числа |
| 3 — Трудные | 7–8 лет | замены, перевороты, перестановка букв цифрами, сочетание двух-трёх приёмов в одном ребусе |

В файле ребусы идут от лёгких к трудным. Баланс уровней примерно 20 / 20 / 15.

## Разнообразие

Ребёнку скучно, когда ребусы похожи друг на друга. Разнообразие — такое же требование к набору, как правильность. Набор разнообразен в четырёх измерениях:

- **Приёмы.** Внутри уровня соседние ребусы устроены по-разному: не больше двух подряд с одним набором приёмов. Ни один набор приёмов не занимает больше ~40 % уровня. На уровне 1 запятые чередуются с первыми буквами, числами и целыми картинками; на уровне 3 замены — с перестановками, переворотами, буквами в букве.
- **Темы.** Животные, птицы, насекомые, еда, фрукты и овощи, игрушки, дом и посуда, одежда, транспорт, природа и погода, сказочное — вперемешку, не больше трёх ребусов одной темы подряд.
- **Картинки.** Чем больше разных эмодзи, тем лучше; лимит повторов считает валидатор.
- **Длина и форма слов.** Короткие и длинные ответы чередуются; ребусы из одной картинки — с ребусами из двух-трёх частей.

Приёмы проверяет валидатор (предупреждения), распределение по уровням показывает `npm run stats`. Темы и длину слов проверяйте сами.

## Этапы

В игре каждый уровень делится на **этапы по 20 ребусов** (короткий хвост меньше 10 присоединяется к предыдущему этапу), за каждый этап ребёнок получает кубок. Этап — это 20 ребусов подряд в порядке файла. Поэтому:

- каждый этап должен быть интересным сам по себе: разнообразие (см. выше) соблюдается и внутри любых 20 подряд;
- внутри этапа ребусы идут от лёгких к трудным, а следующий этап начинается чуть труднее, чем начинался предыдущий;
- добавляя ребусы, не ставьте их все в конец уровня: последний этап не должен получиться самым однообразным.

## Качество ребуса

- **Основную часть ответа дают картинки.** Буквами пишем не больше трети ответа. Больше половины считается ошибкой: «🍯 + ВЕДЬ» — это не ребус, а подглядывание. В ответе из 3–5 букв пишем не больше одной буквы (на уровне 1 можно две).
- **Картинки не должны слишком часто повторяться.** Лимит зависит от размера набора: не больше 4 раз или 2,5% ребусов, если это больше (при 300 ребусах — до 8). Точное число считает валидатор. Чем разнообразнее картинки, тем лучше.
- **Одна и та же схема не повторяется.** Нельзя делать второй ребус на «КИТ, И = О» (так был удалён КОТЛЕТА). Одна и та же «картинка + операция» (например, «🔑 КЛЮЧ,») — не больше двух раз в наборе и не в соседних ребусах.
- **Ответ не встраивает другой ответ набора**: РОГ → НОСОРОГ, ЧАЙ → ЧАЙКА, РЫСЬ → КРЫСА. Ответ не «вырастает» из своей картинки: СЛОН → СЛОНЁНОК, РОЗА → ГРОЗА.
- **Без зеркальных пар**: ответ одного ребуса не должен быть картинкой другого.

## Подсказка `hint`

Подсказка обязательна. Её показывают по кнопке после двух ошибок.

- Короткая загадка про ответ, понятная ребёнку: «Каркает на заборе».
- Подсказка **не называет ответ и не содержит однокоренных слов.** Нельзя «Плетёт паутину» для ПАУКА и «Детёныш слона» для СЛОНЁНКА. Валидатор ловит только прямое вхождение ответа, корни проверяйте сами.
- Подсказка **конкретная**: «С ней играют дети» подходит к чему угодно. Хорошо описать вид, место или действие.
- Если на картинке легко ошибиться со словом, подсказка может мягко его направить, но без однокоренных слов (РЫБАК: «Сидит с удочкой у речки и ждёт, когда клюнет»).

## Без повторов

- Ответы и `id` не повторяются. Это проверяет валидатор.
- Не возвращаем удалённые ребусы, если нет нового решения их проблемы:
  - ВЕЛОСИПЕД, ПОМИДОР, ЛАСТОЧКА — больше половины ответа написано буквами;
  - КОТЛЕТА — повтор схемы КОТ;
  - ПАУТИНА — 🦆 «уточка» плюс много букв;
  - НОСОРОГ — сначала перевёрнутая гора не узналась, потом в него встраивался ответ РОГ;
  - МЫЛО, АИСТ, ЛИСА (через 🍁), РАКЕТА, КАРМАН, ШУТКА — по причинам из таблицы ловушек;
  - ЁЛКА — 🐿️ дети называют «бурундук», ответ совпадает с картинкой 🌲, зеркальная пара с БЕЛКОЙ;
  - МЕДУЗА — половина ответа буквами, 🍯 «банка», МЁД → МЕ (Ё/Е);
  - ЧАЙКА — встраивает другой ответ набора (ЧАЙ); КРЫСА — та же схема, что РЫСЬ, почти омоним КРЫШИ; СЛОНЁНОК — ответ вырастает из картинки;
  - ПАУК, КИНО, ЛУЖА, ЛАСТИК — половина ответа буквами (плюс перегруженные 🐳, 🧅 и повторы схем);
  - ГРОЗА, БАНТ, ПАЛКА, КЛЮКВА, ИКРА — повтор «картинки + операции» (🌹 как в КОЗЕ, БАНАН как в КАБАНЕ, ЁЛКА ,1, КЛЮЧ 1,, КРАБ 1,); у КЛЮКВЫ ещё и малознакомое слово, у ИКРЫ — взрослая подсказка;
  - ЯМА, ВОКЗАЛ, ОРЕХ, СОК, ТРАКТОР — перевёрнута симметричная или плоская картинка (⚽, 👁️, 🪶, 🥥, 🗺️);
  - МОСТ, КИСТЬ, ЦАПЛЯ — картинки-ловушки (🦴 «косточка», 💧 «капелька»), у КИСТИ ответ — «кисточка»;
  - ГРАЧ — детям 6–7 лет слово почти незнакомо, скажут «ворона»;
  - ИГЛА — ребёнок скажет «иголка».

## Формат

```json
{
  "id": "vorona",
  "answer": "ВОРОНА",
  "accept": [],
  "level": 3,
  "hint": "Каркает на заборе",
  "parts": [
    { "type": "pic", "emoji": "👑", "word": "КОРОНА", "replace": [["К", "В"]] }
  ],
  "source": "https://…"
}
```

`id` — латиницей, транслит ответа. Остальные примеры смотрите в самом файле.

## Чек-лист для каждого ребуса

- [ ] Ребёнок назовёт каждую картинку именно словом `word`.
- [ ] Ответ знаком ребёнку этого уровня.
- [ ] Картинки дают основную часть ответа, буквами написано не больше трети.
- [ ] На одной картинке одна операция; приём подходит уровню (таблицы в «Запись ребуса»).
- [ ] Соседние ребусы устроены по-разному, приём не перебирает свою долю уровня (`npm run validate`).
- [ ] Перевёрнутая картинка узнаётся вверх ногами и выглядит иначе, чем в обычном виде.
- [ ] Ё и Е картинки совпадают с Ё и Е ответа.
- [ ] Подсказка конкретная и без ответа и однокоренных слов.
- [ ] Ответа и той же схемы ещё нет в наборе, ответ не встраивает другой ответ и не стоит картинкой в другом ребусе, картинка не превышает лимит (`npm run stats`).
- [ ] `npm run validate` — «проблем: 0».
