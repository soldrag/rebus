# Ребусы для детей

Ребусы на русском для детей 5–8 лет. Работает в браузере, ставится на телефон как приложение и открывается без интернета. Прогресс хранится только в браузере (localStorage). Трекеров и внешних запросов нет.

## Разработка

```sh
npm ci
npm run dev        # локальный сервер
npm run validate   # проверка ребусов
npm run proposals  # проверка замыслов (data/proposals)
npm run diversity  # доли приёмов по уровням
npm run stats      # какие ответы и картинки уже есть
npm run spelling   # заполнить notMisspelled: похожие на ответ настоящие слова
npm run build      # проверка + сборка в dist/
npm run check:screens  # вёрстка на 15 размерах телефонов и планшетов (нужен запущенный `npx vite preview`; Playwright — в devDependencies, браузер: `npx playwright install chromium`)
npm run check:scenarios  # сценарии ребёнка: ответ, «Пишется так», подсказка, разбор, легенда, кубок, Enter, доски всех ребусов (тоже с `npx vite preview`)
```

## Устройство

- `public/data/rebuses.json` — все ребусы (данные отдельно от кода); как их составлять — [docs/REBUSES.md](docs/REBUSES.md)
- `src/core/` — правила ребуса без DOM (их же используют `tools/`): `solve.js` — как части складываются в ответ (запятые, зачёркнутые буквы, замены, перевёрнутые картинки, предлоги) и какие в ребусе приёмы; `answer.js` — проверка ответа ребёнка и орфографии; `format.js` — можно ли ребус нарисовать и решить (проверка при загрузке); `stages.js` — этапы уровня
- `src/legend-data.js` — примеры карточек легенды «?» (рисует `src/ui/legend.js`)
- `TODO.md` — отложенные идеи (доступность для незрячих)
- `src/ui/` — экраны, `src/store.js` — прогресс, `src/install.js` — установка на главный экран
- `src/ui/keyboard.js` — своя экранная клавиатура для ответа (ЙЦУКЕН + Ё). Системную на экране ребуса не открываем: на iPhone над ней всегда есть полоска ↑↓✓, которую страница убрать не может, плашка адреса Safari наезжает на кнопки, а экран прыгает, когда клавиатура выезжает. Поле ответа — не `<input>`, поэтому системная клавиатура не появляется. На ПК и планшете с клавиатурой можно печатать и на обычной: буквы, Backspace, Enter; латиница сопоставляется с ЙЦУКЕН по физическим клавишам, раскладку переключать не нужно
- `tools/validate.mjs` — проверяет, что каждый ребус складывается в свой ответ, и правила автора; `tools/check-proposals.mjs` — то же для замыслов; общие правила обоих (исключения, легенда, подсказка, зеркальные пары) — `tools/rules.mjs`
- `tools/spelling.mjs` — по словарю ищет слова, которые звучат как ответ, но ошибкой в нём не считаются
- PWA (манифест, service worker) генерирует `vite-plugin-pwa`

### Формат ребуса

```json
{
  "id": "vorona", "answer": "ВОРОНА", "accept": [], "level": 2, "theme": "птицы", "techniques": ["replaceAt"],
  "hint": "Каркает на заборе",
  "parts": [
    { "type": "pic", "emoji": "👑", "word": "КОРОНА", "replaceAt": [[1, "В"]] }
  ]
}
```

Часть `pic`: `cutStart` / `cutEnd` — запятые до/после картинки, `flip` — картинка вверх ногами, `remove` — зачёркнутые буквы, `replace` — замена буквы на букву вида `[["К","Р"]]`, `replaceAt` — замена по номеру буквы вида `[[1,"В"]]` (КОРОНА → ВОРОНА), `pick` — номера букв, которые взять. Остальные виды частей и поля — [docs/REBUSES.md](docs/REBUSES.md).

Поля `theme`, `techniques`, `source`, `exceptions` нужны только автору и проверкам: в сборке (`dist/data/rebuses.json`) их нет, как и пустых `accept` и `notMisspelled` (`vite.config.js`, `compactData`).
