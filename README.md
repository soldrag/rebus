# Ребусы для детей

Статическая страница с ребусами на русском для детей 5–8 лет. Прогресс сохраняется в браузере (localStorage).

- `index.html`, `css/`, `js/` — интерфейс
- `data/rebuses.js` — набор ребусов
- `js/rebus-core.js` — правила ребуса (запятые, зачёркнутые буквы, замены, перевёрнутые картинки)

Проверка данных: `node tools/validate.mjs`

## GitHub Pages
Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
