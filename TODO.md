# На будущее

## Доступность для незрячих детей

Идея нравится, но требует переделки приложения целиком — отложено.

- Сейчас у картинок ребуса подпись для экранного диктора — просто «картинка»: слово картинки
  подсказало бы ответ. Тот же принцип принят и для своих иллюстраций (docs/ILLUSTRATIONS.md).
- Опираться на встроенные средства телефонов и планшетов, а не на свою озвучку: экранный диктор
  (VoiceOver на iPhone/iPad, TalkBack на Android), увеличение, крупный шрифт, высокий контраст.
  Наша задача — правильная разметка (роли, подписи, порядок чтения, живые области), а читает
  и озвучивает система. Слабовидящим — уважать системные настройки размера текста и контраста.
- Чтобы незрячий ребёнок мог разгадывать, нужен отдельный режим: ребус читается диктором как загадка
  по шагам («картинка: кот; убираем первую букву…») — со своими формулировками для каждого приёма
  (запятые, замены, отношения), без раскрытия ответа раньше времени.
- Затронет: разметку доски (src/ui/board.js), легенду, разбор, порядок фокуса, озвучку итога,
  тесты экранов. Нужен отдельный дизайн и проверка с диктором (VoiceOver, TalkBack).

## Пояснения к новым словам

Ребус может вести к слову, которое ребёнок ещё не знает (ВЕЛИКАН, ПАПКА). После разгадки можно
показать короткое пояснение простыми словами («Великан — очень-очень большой человек из сказок»).
Нужно: поле с пояснением в данных ребуса, место на экране итога, правила написания для авторов.
